# 地址簿接口

## 地址详情修改

`PUT /api/address/update` 用于修改当前用户自己的地址。`id` 必填；校区、楼栋、详细地址和
标签只更新请求中明确提供的字段。

`details` 和 `label` 的更新语义如下：

- 不传或传 `null`：保留原值。
- 传非空字符串：替换原值。
- 传空字符串：清空原值。

必须区分“未提供”和“主动清空”，否则用户在地址详情页删除已有标签或详细地址后，接口会
表面成功但数据库仍保留旧内容。小程序清空 TDesign 输入框时也必须监听 `clear` 事件，将
页面状态同步为空字符串。

## 验证

1. 打开一个已有标签和详细地址的地址。
2. 分别点击输入框的清空按钮并保存。
3. 重新进入地址详情，确认被清空的字段仍为空；修改为其他文字后再次保存也应成功。
4. 只修改默认地址或楼栋时，未提供的可选文本字段应保持不变。

## 回滚

本调整不改变数据库结构，回滚 API 和小程序代码即可，不需要执行数据库迁移。已经由用户
主动清空的标签或详细地址不会自动恢复，若需恢复只能由用户重新填写或从业务备份找回。
